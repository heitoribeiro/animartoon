# Animartoon — AI Animation Studio

MVP da Sprint 1 da plataforma de produção de animação assistida por IA.

## Escopo atual
- Próxima ação como página operacional principal.
- Pipeline imagem → animação com/sem fala → aprovação.
- Sugestão padronizada de nomes de arquivos e versões.
- Links diretos para Gemini, SnapGen, Meta AI, Vibes e Grok.
- Ferramentas preferidas e perfil básico dos geradores.
- Modos de armazenamento: Google Drive Online, Google Drive no computador e controle manual.
- Mapa de arquivos, auditoria e persistência local do andamento.

## Roadmap imediato
- criação/importação real de projetos;
- decupagem de vídeo/YouTube;
- IndexedDB;
- Google Drive Online;
- File System Access API;
- leitura real de nomes/versões;
- auditoria real;
- perfis de geradores editáveis.
